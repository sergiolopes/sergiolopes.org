# Mirrors externos do arquivo

Este inventário reúne cópias históricas de publicações originalmente mantidas em Caelum, Alura, iMasters, Medium, RevistaW e Loopinfinito. Cada entrada de `src/data/mirrors.json` foi montada a partir de uma captura HTML efetivamente baixada do Wayback; o timestamp e os links são mantidos para auditoria.

## O que foi recuperado

- **37 de 37 publicações** têm captura HTML histórica recuperada: 30 da coleção Caelum/Alura e 7 de outras publicações.
- `archiveUrl` é o link normal da captura no Wayback; `archiveReplayUrl` é o replay direto usado na coleta.
- `originalUrl` é a URL registrada no DocPad antigo. `currentUrl`/`currentStatus` são apenas evidência do estado observado em 19/09/2026; não substituem a cópia histórica.
- O HTML preserva o corpo do artigo, headings, listas, código, imagens e iframes encontrados na captura. Removi menus, analytics, widgets de compartilhamento, comentários, gravavatars e blocos de recomendação do site de origem.
- Scripts e componentes dinâmicos não são executados no site estático. O conteúdo textual e os embeds que estavam no corpo continuam registrados; handlers `onclick` e o script condicional de vídeo foram removidos.

## Integração no Astro

- `html` é um fragmento sem o título; o renderer deve usar `title`, `date`, `originalUrl` e `archiveUrl` no cabeçalho/rodapé.
- `assetMap` liga cada URL histórica à cópia em `public/mirrors/`. O renderer precisa prefixar os caminhos com `import.meta.env.BASE_URL` para o deploy em `/sergiolopes.org/`; o mesmo helper poderá funcionar quando o domínio próprio estiver na raiz.
- `assetPaths` contém apenas arquivos realmente presentes e validados. `assetSources` lista todas as referências originais encontradas, inclusive as que ficaram remotas. Referências sem cópia local viram um fallback textual com link para `archiveUrl`, evitando imagem quebrada silenciosa.
- A seção `recoverySource` registra o seletor de extração usado (`entry-content`, `entry`, layouts antigos, iMasters, Medium, RevistaW ou Setup), facilitando revisão de casos especiais.

## Limites conhecidos

- A cópia não inclui comentários/discussões do site de origem. Isso evita trazer widgets, trackers e conteúdo de terceiros para o arquivo pessoal.
- Páginas com demos, PHP, formulários, scripts externos ou conteúdo carregado depois do HTML foram preservadas como HTML histórico quando possível; o comportamento executável não faz parte do deploy estático.
- O conteúdo de iMasters retornou HTTP 429 no acesso atual, e Medium retornou 403; isso não impede os mirrors porque as capturas Wayback foram baixadas. RevistaW redireciona hoje para a home e Loopinfinito continua disponível no endereço original.
- O PHP do repositório antigo permanece fora desta migração conforme solicitado; os redirects de `.htaccess` devem ser gerados pelo migrador como páginas HTML estáticas.
